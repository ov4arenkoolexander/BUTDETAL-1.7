# Як отримати APK «Будівельник UA»

У проєкті є автоматична збірка через GitHub Actions. Workflow використовує Android SDK, попередньо встановлений на runner GitHub, і окремо встановлює platform-tools, Android Platform 35 та Build Tools 35.0.0. Вона створює встановлюваний тестовий APK `app-debug.apk`. Цей файл не є підписаним релізом для Google Play.

## Варіант A — найпростіший: збірка онлайн через GitHub

1. На GitHub створи новий репозиторій, наприклад `BudivelnykUA`. Для приватного проєкту вибери **Private**.
2. Розпакуй архів `BudivelnykUA_Android_Project_v1.5_FIXED.zip` на комп'ютері.
3. Завантаж у репозиторій **усі файли й папки зсередини** розпакованої папки. У корені репозиторію мають лежати `settings.gradle`, `build.gradle`, папка `app` та папка `.github`.
4. Відкрий вкладку **Actions**. Якщо GitHub запропонує увімкнути Actions, погодься.
5. Робочий процес **Build Budivelnyk UA APK** стартує після завантаження файлів. Якщо ні — відкрий його, натисни **Run workflow** → **Run workflow**.
6. Дочекайся зеленої позначки успіху, відкрий завершений запуск унизу сторінки й знайди **Artifacts**.
7. Завантаж `Budivelnyk-UA-debug-APK.zip`, розпакуй його — всередині буде `app-debug.apk`.
8. Передай APK на Xiaomi 14T і відкрий його для встановлення. Android може попросити дозволити встановлення застосунків із цього джерела — вмикай дозвіл лише для програми, якою ти сам відкрив APK, і після встановлення можеш вимкнути його.

## Варіант B — локально через Android Studio

1. Встанови Android Studio та JDK 17.
2. В Android Studio відкрий саме кореневу папку проєкту — ту, де `settings.gradle`.
3. У SDK Manager встанови **Android SDK Platform 35** і **Android SDK Build-Tools 35.0.0**.
4. Дочекайся завершення Gradle Sync. Якщо Android Studio запропонує завантажити потрібні компоненти Gradle — погодься.
5. Обери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Готовий файл зазвичай з'явиться тут: `app/build/outputs/apk/debug/app-debug.apk`.

## Що входить

- Android-застосунок із назвою «Будівельник UA».
- Україномовний офлайн-довідник у локальному HTML-файлі.
- Окремі архіви «Креслення» та «Фото виробів» із додаванням і видаленням фото.
- Калькулятор об'єму бетону, формули, таблиці й теоретична маса арматури, як реалізовано в поточній версії інтерфейсу.

## Важливо

- APK у GitHub Actions збирається автоматично, але до запуску workflow я не можу стверджувати, що конкретна збірка пройшла успішно на твоєму пристрої. Якщо збірка впаде, відкрий червоний запуск у **Actions**, скопіюй останні 30–50 рядків помилки та надішли їх — за ними можна виправити проєкт.
- Це **debug APK** для встановлення й перевірки. Для публікації в Google Play потрібна окрема release-збірка та підпис ключем.
- Фото зберігаються у приватному сховищі застосунку; при видаленні застосунку вони можуть зникнути. Зберігай важливі креслення окремо.
- Інженерні формули та розрахунки довідкові й не замінюють перевірені робочі креслення конструктора.
