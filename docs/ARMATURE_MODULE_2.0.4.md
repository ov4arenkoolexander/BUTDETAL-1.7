# BUTDETAL 2.0.4 — модуль «Армування»

## Підтверджені вимоги
- Вхідні креслення: фото, скани та PDF.
- Розпізнавання: український, російський та англійський текст; текст, розміри, марки конструкцій, позначення арматури, таблиці та специфікації.
- Два режими: побудова креслення за заданими параметрами; розрахунок і креслення за обраними нормами.
- Усі OCR-значення проходять ручне підтвердження перед використанням.
- Оригінали зберігаються окремо від розпізнаних даних.
- Експорт схеми та специфікації в PDF.

## Архітектура
1. UI: плитa, балка, колона, фундамент; форма параметрів і попередній перегляд.
2. Імпорт: Android Storage Access Framework для фото/PDF.
3. PDF: Android PdfRenderer для рендерингу сторінок.
4. OCR: Tesseract із трьома моделями: українська (`ukr`), російська (`rus`) та англійська (`eng`); робочий комбінований режим `ukr+rus+eng`. Gradle task `downloadTesseractModels` автоматично завантажує офіційні моделі `tessdata_fast` у `app/src/main/assets/tessdata/` перед `preBuild`. Для першої збірки потрібен інтернет; після включення моделей у APK розпізнавання працює без інтернету. Потрібно перевірити збірку, розмір APK та якість на реальних кресленнях.
5. Парсер: кандидати розмірів, Ø/⌀, марки сталі, кроки, марки конструкцій, таблиці.
6. Перевірка: координати джерела, сторінка, впевненість OCR і підтвердження користувача.
7. Креслення: векторні плани, перерізи, виноски, позиції та специфікації.
8. Розрахунок: окремий тестований модуль за обраною редакцією норм; за відсутніх вхідних даних не видавати результат.

## Межі першого прототипу
Перший етап — лише параметрична геометрична візуалізація та попередня відомість. Він не виконує нормативного розрахунку і не видає робоче креслення. Підбір арматури, анкеровки, нахлестів, захисного шару та перевірки міцності потребують повного набору даних і перевірки інженером.

## Критерії приймання
- Схема оновлюється при зміні параметрів.
- Збережені проєкти відкриваються після повторного запуску.
- Фото та PDF імпортуються, оригінали не змінюються.
- Сумнівні OCR-поля виділяються і не підтверджуються автоматично.
- Відомість та PDF містять одиниці виміру, вихідні параметри й застереження щодо статусу розрахунку.
