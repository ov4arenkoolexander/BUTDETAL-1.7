# Будівельник UA 1.7

Офлайн Android-довідник українською мовою для Xiaomi та інших Android-пристроїв.

## Швидко отримати APK

Дивись інструкцію [`BUILD_APK_UA.md`](BUILD_APK_UA.md). У проєкті є GitHub Actions workflow `.github/workflows/build-apk.yml`, який автоматично збирає debug APK та додає його до Artifacts.

## Проєкт

- Android application ID: `ua.budivelnyk.ua`
- Мінімальна Android-версія: Android 6.0 (API 23)
- Compile/Target SDK: 35
- Java: 17
- Gradle: 8.9
- Дані застосунку зберігаються локально; мережа не потрібна для основних функцій.

Функції поточної версії: офлайн-довідник, формули й таблиці, калькулятор об'єму бетону, розрахунок теоретичної маси арматури, окремі папки фотоархіву «Креслення» та «Фото виробів».

**Статус:** проєкт підготовлений до автоматичної збірки, але APK не додається до ZIP і не позначається як перевірений, доки workflow фактично не завершиться успішно.


## Версія 1.7 — каталог виробів
- На головній сторінці є пошук збережених виробів за назвою, маркуванням, типом, розмірами та примітками.
- Картка виробу зберігає тип, розміри, об'єм на одиницю, кількість, армування та примітки.
- До картки можна додати декілька фото виробу та креслень/схем армування.
- Метадані каталогу зберігаються локально у WebView; фото та креслення — в окремих внутрішніх папках застосунку.
- Каталог працює офлайн. Видалення картки не видаляє фотографії з архіву.
